# saidso with Cursor

Copy [mcp.json](mcp.json) to `.cursor/mcp.json` in your project (or `~/.cursor/mcp.json` for all projects),
set `SAIDSO_ROOM` to your room folder, and restart Cursor. Add the rules from
[the Claude Code example](../claude-code/README.md#2-tell-claude-how-to-behave-claudemd-or-agentsmd) to `.cursor/rules`.
